# Proposal

Status: Implemented

## Why

`public/engineering/adr.md` is a C4 / arc42-style architecture description. It is not an architecture decision record.

## What Changes

- Rename `public/engineering/adr.md` to `public/engineering/architecture-doc.md`.
- Set the title to "Architecture document" and state that decision records are a separate template.
- Add `public/engineering/adr.md` as a one-page architecture decision record: Title, Status, Context, Decision, Consequences, plus Date, Deciders, and Related links.
- Cite Michael Nygard, Documenting Architecture Decisions (15 November 2011).

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None.

## Impact

`public/engineering/architecture-doc.md` and `public/engineering/adr.md`.
