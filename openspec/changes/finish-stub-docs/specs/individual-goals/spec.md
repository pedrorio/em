# Spec Delta

## Purpose

States that the goals template is one person's goals, so it is not confused with a team or domain operational review.

## ADDED Requirements

### Requirement: Goals are one person's
The goals template SHALL say the goals belong to one person. It SHALL keep owner, reporter, date, next date, objective, and key results, and SHALL name the ladder dimension for the objective.

#### Scenario: Reader opens goals
- **WHEN** a reader opens the goals template
- **THEN** it is labelled as one person's goals and it still has owner, reporter, dates, an objective, and key results
