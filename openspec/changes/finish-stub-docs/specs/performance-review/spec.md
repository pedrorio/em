# Spec Delta

## Purpose

Completes the performance review so a rating on the four-point scale ends in a promotion case, an underperformance plan, or no change.

## ADDED Requirements

### Requirement: Review ends in one outcome
The performance review SHALL keep the self rating, the manager rating, and the perception gap, SHALL keep the four-point scale, and SHALL name the outcome as a promotion case, an underperformance plan, or no change.

#### Scenario: Manager closes a review
- **WHEN** a manager completes the performance review
- **THEN** it shows both ratings, the perception gap, the four-point scale, and one of those three outcomes
